About this project

What this is

A reading edition of William Edward Hartpole Lecky’s major works, built page by page rather than published all at once. The design borrows its reading philosophy — semantic zoom, footnotes you can hover to preview, and links that pop up what they point to — from Gwern Branwen’s gwern.net. The site’s code is our own; the footnote and popup styling is adapted from gwern.net’s stylesheet, which Gwern publishes under CC0/MIT licenses.

Current status

The typography, layout, footnote system, and hover-popup mechanism are built and working. Real text has started landing: the Introduction to Rise and Influence of Rationalism in Europe is sourced, OCR-cleaned, and proofread against the scan.

There is no clean transcription of this title anywhere (it isn’t on Project Gutenberg or Wikisource), so each chapter comes from a 160-year-old library scan’s raw OCR, run through an automated cleanup pass and then read through by hand before publishing. That means it goes up one chapter at a time rather than all at once.

Next steps, in order:

  1. Clean and proofread Volume I, Chapter I (roughly 150 printed pages — the longest chapter in the book), then continue through the rest of Volume I and Volume II.
  2. Identify every work, document, and figure Lecky cites, and build reference pages for them — starting with the source texts (the witchcraft manuals, pamphlets, and letters), each transcribed in full where we can find them.
  3. Wire citations in the main text to hover-previews and click-throughs into those reference pages.
  4. A cross-reference map of how it all connects.

On the text

Lecky’s writing and the primary sources he cites are in the public domain. Where we rely on a particular library scan or edition, we credit it on the relevant page.

The text of Lecky's works is in the public domain. Annotations, reference transcriptions, and site design are original work of this project. Source on GitHub.
